# План развития Agent Skills

Инструкция по установке, подключению скиллов и делегированию находится в README. Здесь — две задачи, которые остаётся закрыть. [Как пользоваться набором](../README.md)

## Проверить установку в чатах

Проверки команд CLI уже покрыли установку из закреплённого коммита, доустановку после ошибки выбора скилла и размещение файлов для Claude Code. Осталось пройти пользовательский сценарий с актуальным набором в Codex и Claude Code.

- В пустой папке агент уточняет стек и ставит нужные скиллы.
- В существующем проекте агент сохраняет старые инструкции. Повторная настройка добавляет только недостающее.
- После сбоя установка продолжается с той же ревизии. В новом чате задача, для которой нужен ещё один профиль, подхватывает его из этой ревизии.

## Проверить пользу младшей модели

Для работы с младшей моделью уже есть инструкция. Осталось проверить её на обычных задачах с понятной приёмкой и разрешённым делегированием. В журнале отмечаем, прошла ли правка проверку с первого раза, сколько времени заняла и сколько ресурсов ушло на обоих агентов с учётом переделок. [Шаблон журнала](../skills/deliver-feature/references/task-results.md)

Решение о регулярном делегировании принимаем для конкретного типа задач, когда записи показывают сопоставимое качество, приемлемое время и меньший общий расход. Если клиент не показывает общий расход, экономия в токенах остаётся неподтверждённой.
