# Go Backend

- Определи версию по `go.mod` и фактическому toolchain. Найди регистрацию маршрута, ближайший обработчик, middleware и тесты. Сохраняй принятые маршрутизацию, формат ошибок, коды ответа, проверки доступа и различие между отсутствующим и нулевым значением.
- Валидируй ввод на границе API. Передавай контекст запроса в блокирующие вызовы. Отображай ошибки домена в HTTP в принятом слое. Для `database/sql` закрывай набор строк и проверяй `rows.Err()` при ручном обходе.
- У каждой горутины определи владельца, сигнал остановки и способ дождаться окончания. Учитывай отмену в блокирующих отправках и приёмах. Для общей памяти сохрани единый способ синхронизации, а для канала закрепи ответственность за закрытие за владельцем отправки.
- Проверяй изменённый контракт через зарегистрированный handler или существующий интеграционный сценарий. Для изменений конкурентности проверь отмену или остановку и прогоняй `go test -race` на затронутом пакете, если меняется синхронизация либо доступ к общей памяти. Сбой записи и отмену проверяй через контракт фактического вызывающего кода.

Сверяй спорное поведение по документации toolchain проекта. Для транзакций через стандартный драйвер см. [руководство Go](https://go.dev/doc/database/execute-transactions).
