# OpenPencil

Если доступен официальный скилл `open-pencil`, используй его для работы с инструментами редактора. Сверь доступные операции по схемам подключённого MCP. При ограничении доступа выделением попроси пользователя выбрать нужный кадр, если он ещё не выбран.

1. Определи документ, страницу, кадр и состояние. Для выбранного кадра начни с `get_selection`. Когда доступны идентификаторы документа и страницы, передавай их явно в вызовы, которые их поддерживают. Запроси свойства кадра и затронутых слоёв через `get_node` и получи изображение того же кадра через `export_image`. Если макет состоит из одной вставленной картинки, замеры по ней указывай как приблизительные.
2. Для каждого затронутого кадра прочитай настройки раскладки родительских фреймов и размеры дочерних слоёв. Зафиксируй, какой фрейм задаёт padding, gap и выравнивание, какие зоны фиксированы, тянутся или растут по содержимому. Проверь текстовые стили, переменные и главный визуал. Для реализации в приложении передай правила контейнеров вместе с экспортом кадра по `build-from-design`.
3. При сборке или правке на холсте применяй эти правила во всех затронутых кадрах. Сначала настрой раскладку родительских фреймов, затем помести в них вложенные группы и переиспользуемые компоненты. Сохрани редактируемые слои и привязки к переменным. Учитывай внутренние поля экземпляра при выборе его варианта и отступов контейнера. Для деталей, которых нет в референсе, используй правила соседних кадров и принципы группировки из `build-from-design`.
4. Сопоставь изменённые кадры с соответствующими референсами при одинаковой ширине и состоянии. Экспортируй нужные кадры для сравнения. Для двух сопоставимых узлов можно использовать `diff_pixels`, если сервер его предоставляет. Для реализации в приложении сравни фактический рендер с экспортом кадра.
