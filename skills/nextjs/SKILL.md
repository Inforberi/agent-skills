# Next.js

1. Найди пакет приложения и определи версию `next` по установленному пакету или lockfile. По структуре и ближайшим маршрутам определи, используется ли App Router или Pages Router в затронутой части.
2. До выбора API прочитай относящийся к задаче раздел из `next/dist/docs/`, если он есть в установленном пакете. Иначе используй официальные материалы для версии приложения. Учитывай локальные правила и документацию из [руководства Next.js для агентов](https://nextjs.org/docs/app/guides/ai-agents).
3. Сохраняй соглашения роутера, существующие границы между сервером и клиентом и гарантии работы с данными. Сверяй кеширование, повторную валидацию и поведение при навигации, когда они относятся к изменению. Ограничивай клиентскую область компонентами, которым нужны клиентские возможности.
4. Используй команды пакета приложения. Проверь затронутый маршрут через обычную точку входа. Если поведение зависит от кеша или серверного рендера, включи проверку в соответствующем режиме проекта.
