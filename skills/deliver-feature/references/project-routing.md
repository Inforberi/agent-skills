# Правило для инструкций проекта

Добавьте этот короткий блок в существующий файл инструкций, который читает ваш агент. Оставьте действующие правила рядом с ним.

```markdown
## Рабочий процесс по фичам

Для многошаговой фичи используй установленный `deliver-feature`. До реализации определи пользовательский сценарий, границы работы и проверяемые критерии. Для задачи по макету подключай `build-from-design`, для новой поверхности без макета — `design-from-brief`, для токенов и общих компонентов — `design-system`. Проверяй первый рабочий сценарий до расширения покрытия. Небольшие правки выполняй напрямую с целевой проверкой.
```
