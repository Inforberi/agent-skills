# Правило для инструкций проекта

Добавьте этот короткий блок в существующий файл инструкций, который читает ваш агент. Оставьте действующие правила рядом с ним.

```markdown
## Рабочий процесс по фичам

Используй установленный `deliver-feature` для изменений поведения, задач из нескольких связанных шагов и отдельного сбора данных с заданным результатом. Применяй его правило автоматического делегирования с учётом возможностей клиента и ограничений проекта. Небольшие правки выполняй напрямую с целевой проверкой.
```
