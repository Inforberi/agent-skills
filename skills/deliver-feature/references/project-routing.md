# Правило для инструкций проекта

Добавьте этот короткий блок в существующий файл инструкций, который читает ваш агент. Оставьте действующие правила рядом с ним.

```markdown
## Рабочий процесс по фичам

Используй установленный `deliver-feature` для новых сценариев из нескольких связанных шагов. Выбирай режим по масштабу и риску. Небольшие правки выполняй напрямую с целевой проверкой.
```
