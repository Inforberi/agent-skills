## Правила Agent Skills

- Простую локальную правку выполняй напрямую. Для изменения поведения, нескольких связанных шагов или отдельного сбора данных с заданным результатом прочитай и примени `deliver-feature`, даже если пользователь его не назвал.
- Выбирай исполнителя до объёмного чтения или сбора. Если самостоятельный блок оправдывает делегирование, есть способ проверить результат и правила разрешают запуск, выбери самую младшую подходящую модель, которой доступны нужные инструменты и источники. Передай ей точное задание с границами, входными данными, форматом и критериями приёмки. При сбое по качеству следуй правилам перехода на следующую модель из `deliver-feature`. Основной агент проверяет результат. Если делегирование недоступно, продолжи сам.
- Выбирай профиль по задаче. Если нужного скилла из Inforberi/agent-skills нет, прочитай `setup-agent-skills`, установи только недостающий профиль из закреплённой ревизии, прочитай его и продолжи. Graphify устанавливай только по отдельному запросу.
- Для проверки правки найди действующую команду нужного модуля и её рабочий каталог. Начни с инструкций и скриптов проекта, затем проверь конфигурацию тестов или CI.
- Начинай с исходников, команд проекта и доступных API. Если для приёмки нужно интерактивно управлять браузером или приложением, объясни зачем и дождись разрешения на Computer Use. Прямой запрос или заранее данное разрешение действуют в указанных пользователем границах.
