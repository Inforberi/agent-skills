## Правила Agent Skills

- Если после проверки запроса и контекста остаётся неясность, которая может изменить ожидаемый результат, задай конкретный вопрос и дождись ответа перед зависимой частью работы. Когда есть реальные варианты, коротко объясни последствия каждого и порекомендуй один с причиной. Ясные и обратимые решения, оставленные на усмотрение агента, принимай самостоятельно.
- Простую локальную правку выполняй напрямую. Для изменения поведения, нескольких связанных шагов или отдельного сбора данных с заданным результатом прочитай и примени `deliver-feature`, даже если пользователь его не назвал.
- На большой задаче основной агент координирует работу и отвечает за конечный результат. Определи подход и приёмку, затем по умолчанию поручи объёмный сбор информации и реализацию проверяемых частей младшим моделям, если клиент и правила разрешают. Выбирай исполнителя до объёмного чтения, начиная с самой младшей подходящей модели с нужными инструментами и доступом. Передай точное задание с границами, входными данными, форматом и критериями приёмки.
- Запускай до трёх субагентов одновременно для независимых поручений. Разделяй области чтения и правок. Поручай изучение общего модуля одному исполнителю и передавай остальным нужный контекст. У общего файла один владелец правок. Зависимые поручения выполняй последовательно.
- Основной агент проверяет общий результат и стыки, организует исправление расхождений и сообщает о блокерах. При сбое по качеству следуй правилам перехода на следующую модель из `deliver-feature`. Если делегирование недоступно, продолжи сам.
- Сам выбирай профили по запросу, README и инструкциям целевого проекта, его файлам и инструментам, относящимся к задаче. Если нужного скилла из Inforberi/agent-skills нет, прочитай `setup-agent-skills`, установи только недостающий профиль из закреплённой ревизии, прочитай его и продолжи. Graphify устанавливай только по отдельному запросу.
- Для проверки правки найди действующую команду нужного модуля и её рабочий каталог. Начни с инструкций и скриптов проекта, затем проверь конфигурацию тестов или CI.
- Начинай с исходников, команд проекта и доступных API. Если для приёмки нужно интерактивно управлять браузером или приложением, объясни зачем и дождись разрешения на Computer Use. Прямой запрос или заранее данное разрешение действуют в указанных пользователем границах.
