# Agent Skills

Набор помогает агенту подобрать и подключить скиллы для действующего проекта или пустой папки.

## Самый простой способ

Откройте нужный проект в агенте и отправьте сообщение.

> Подключи скиллы для этого проекта по инструкции из https://github.com/Inforberi/agent-skills

Агент прочитает инструкцию, определит стек и установит нужные скиллы. Если из файлов и сообщения непонятно, что вы собираетесь делать, он уточнит. Настройка сохраняется в инструкциях проекта. Клиент может запросить доступ на запись. [Инструкция настройки](skills/setup-agent-skills/SKILL.md)

После настройки откройте новый чат в проекте и описывайте задачи обычным текстом. Codex и Claude Code могут читать один блок правил из `AGENTS.md`. Если для задачи по макету Figma нужен `build-from-design`, агент может добавить его из закреплённой версии набора.

## Через терминал

В корне проекта выполните команду. Нужны Node.js 22.20 или новее и Codex CLI.

```sh
npx --yes skills@1.7.4 use Inforberi/agent-skills --skill setup-agent-skills --agent codex
```

Команда сразу запускает Codex с инструкцией настройки. Для Claude Code замените `codex` на `claude-code`.

Если хотите сначала установить помощника и использовать его в чате, выполните команду ниже. Затем попросите агента «Подключи нужные скиллы для этого проекта».

```sh
npx --yes skills@1.7.4 add Inforberi/agent-skills --skill setup-agent-skills
```

## Как агент выбирает исполнителя

Мелкую правку агент делает сам. Для самостоятельного блока он может составить точное задание и выбрать самую младшую подходящую модель. Если она не проходит проверку по качеству, агент может передать блок следующей подходящей модели. Основной агент принимает результат. Делегирование зависит от возможностей клиента и правил проекта.

Если набор уже установлен, отправьте в чат проекта такой запрос.

> Обнови agent-skills до текущей версии. Возьми актуальную инструкцию настройки из https://github.com/Inforberi/agent-skills

Журнал результатов можно включить отдельно, указав путь к файлу в инструкциях проекта. [Пример правила и записи](skills/deliver-feature/references/task-results.md)
