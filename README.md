# Agent Skills

Переносимые скиллы для AI-агентов. Помогают спланировать задачу, реализовать её и проверить результат. Для интерфейсов в наборе есть отдельные скиллы для работы по макету, UX без макета и дизайн-системы.

## Быстрый старт

1. Откройте терминал в корне проекта, где будете использовать скиллы. Для команды установки нужен Node.js 22.20 или новее.
2. Выполните команду и выберите своего агента в меню установки.

   ```sh
   npx skills@1.7.4 add Inforberi/agent-skills --skill deliver-feature ponytail
   ```

3. Откройте этот проект в агенте и дайте первую задачу.

   > Используй `deliver-feature`. Разберись, как сейчас работает импорт CSV, составь план и критерии приёмки. Затем реализуй поддержку пустых значений и проверь импорт на примере.

В Codex скилл можно вызвать явно через `$deliver-feature`. Установка действует в текущем проекте. Если Ponytail уже есть в агенте, достаточно установить `deliver-feature`.

## Для сайта, CRM или приложения

Чтобы подключить сразу весь базовый набор для интерфейсов, выполните из корня проекта:

```sh
npx skills@1.7.4 add Inforberi/agent-skills \
  --skill deliver-feature design-from-brief build-from-design design-system product-ui ponytail
```

| Задача | Пример запроса |
| --- | --- |
| Реализовать по макету | «Используй `deliver-feature`. Собери страницу по приложенному макету. Проверь первый рабочий сценарий в браузере». |
| Спроектировать без макета | «Используй `design-from-brief`. Предложи варианты очереди заявок CRM и порекомендуй один. Дождись моего выбора». |
| Создать или изменить общие стили | «Используй `design-system`. Сначала настрой токены, типографику и отступы. Затем собери первый экран и проверь смену темы». |
| Поправить интерфейсный текст | «Используй `product-ui`. Проверь заголовок и подпись кнопки. Сверь их с тем, что реально делает экран». |

`deliver-feature` выбирает подходящие из установленных скиллов. Для крупной работы сначала задаёт критерии приёмки, затем проверяет первый рабочий сценарий и расширяет реализацию. При доступном делегировании распределяет подготовку, реализацию и проверку между моделями.

## Как выбрать скиллы

| Скилл | Когда пригодится |
| --- | --- |
| [`deliver-feature`](skills/deliver-feature/SKILL.md) | Фича или несколько связанных шагов. От плана до приёмки. |
| [`ponytail`](skills/ponytail/SKILL.md) | Простая реализация на существующих средствах проекта. |
| [`design-from-brief`](skills/design-from-brief/SKILL.md) | Проектирование нового сценария или экрана без макета. |
| [`build-from-design`](skills/build-from-design/SKILL.md) | Реализация по Figma, скриншоту или визуальной спецификации. |
| [`design-system`](skills/design-system/SKILL.md) | Глобальные стили, токены, типографика, отступы и композиция компонентов. |
| [`product-ui`](skills/product-ui/SKILL.md) | Последовательность интерфейса, точные тексты и состояния. |
| [`nextjs`](skills/nextjs/SKILL.md), [`sveltekit`](skills/sveltekit/SKILL.md) | Дополнительный профиль для текущего фреймворка. Добавьте его в список после `--skill`. |

## Другие способы подключения

- **Конкретный агент.** Добавьте `--agent codex` или `--agent claude-code`. Для обоих укажите `--agent codex claude-code`. См. [список поддерживаемых агентов](https://github.com/vercel-labs/skills/blob/main/docs/agents.md).
- **Локальный клон.** Вместо `Inforberi/agent-skills` передайте абсолютный путь к клону. Для фиксированной версии из GitHub укажите `Inforberi/agent-skills@<тег-или-коммит>` с существующей ревизией вместо шаблона.
- **Вручную.** Скопируйте нужную папку из `skills/` целиком. Для Codex используйте `.agents/skills/`, для Claude Code — `.claude/skills/`. Для других агентов смотрите каталог, который читает выбранный агент.
- **Автоматический выбор для крупных задач.** Добавьте [короткое правило](skills/deliver-feature/references/project-routing.md) в существующий файл инструкций проекта, например `AGENTS.md` или `CLAUDE.md`.

Дополнительно доступны [каталог интеграций и источники сторонних скиллов](docs/catalog.md), [примеры критериев приёмки](examples/acceptance.md) и [шаблоны заданий для реализации и проверки](skills/deliver-feature/references/handoff.md).
