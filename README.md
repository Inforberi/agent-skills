# Agent Skills

Агент сам подбирает и подключает скиллы для вашего проекта. Можно начать с действующего репозитория или пустой папки.

## Самый простой способ

Откройте нужный проект в Codex или другом агенте и отправьте ему [ссылку на этот репозиторий](https://github.com/Inforberi/agent-skills). К ссылке можно добавить «Подключи скиллы для этого проекта».

Агент прочитает [инструкцию настройки](skills/setup-agent-skills/SKILL.md), определит стек и установит нужные скиллы. Если контекста мало, он уточнит, что вы собираетесь делать. Настройка сохраняется в инструкциях проекта. Клиент может запросить разрешение на запись в каталог скиллов.

Дальше описывайте задачи обычным текстом. Если по ходу понадобятся другие скиллы из этого набора, агент подключит их сам. Например, при первой задаче по Figma он добавит профиль для работы по макету.

## Через терминал

В корне проекта выполните команду. Нужны Node.js 22.20 или новее и Codex CLI.

```sh
npx --yes skills@1.7.4 use Inforberi/agent-skills --skill setup-agent-skills --agent codex
```

Команда сразу запускает Codex с инструкцией настройки. Для Claude Code замените `codex` на `claude-code`.

Если хотите сначала установить помощника и использовать его в чате, выполните команду ниже. Затем попросите агента «Подключи нужные скиллы для этого проекта».

```sh
npx --yes skills@1.7.4 add Inforberi/agent-skills --skill setup-agent-skills
```
